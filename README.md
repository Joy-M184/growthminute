# GrowthMinute

GrowthMinute brings two focused tools together under one brand:

- **Growth Plan** for daily accountability, planning, check-ins, and group responses.
- **Cash Flow** for tracking income, expenses, balances, and helpful suggestions.

Visitors can choose Growth Plan only, Cash Flow only, or both products.

## Technology

React, TypeScript, Vinext, Cloudflare D1, Drizzle ORM, and ChatGPT Sites authentication.
